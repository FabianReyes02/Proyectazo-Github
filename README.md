## 📝 Descripción del Proyecto

Página web con un catálogo de videojuegos que muestra imágenes, descripciones y detalles, con vistas organizadas para el usuario.  
En desarrollo se incluirá un sistema de autenticación y conexión con bases de datos.

## 💻 Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/FabianReyes02/Proyectazo-Github.git
````
2.- Ingresar a directorios
```bash
cd Proyectazo-Github
cd Proyecto
cd home
```
3.- Ejecutar archivo
```bash
"home.html"
```
---
4.-
```bash
Instalar la extensión Allow Cords para correcto funcionamiento
```
